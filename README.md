# Проекты Python (Неделя 2)

## Файлы
- `закрепление 2 неделя Pyton.ipynb` — все учебные задачи и финальный проект
- `utils.py` — вспомогательные функции для работы с текстом
- `text.txt` — тестовый файл для анализа
- `screenshot.png` — скриншот работы в IDE

## Запуск
1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти Jupyter: `jupyter notebook`
3. Открой `закрепление 2 неделя Pyton.ipynb`

## Что внутри
- День 1-7: базовые задачи на ввод/вывод, циклы, функции
- Финальный проект: "Консольный помощник по покупкам"
- Обработка ошибок и валидация ввода
